# Support

This guide explains where to get help with this project.
Please choose the channel that matches your situation, it gets you a faster answer.

> [!NOTE]
> Before participating in this community, please read our [Code of Conduct](./CODE_OF_CONDUCT.md). By interacting with this repository or community you agree to abide by its terms.

## Asking Questions

Usage questions are answered in [Discussions](https://github.com/ByteCorum/pyguard/discussions/new?category=q-a), not the issue tracker.

Help us help you. Before asking:

- Search existing discussions and issues, your question may already be answered
- Reduce your question to a [minimal reproducible example](https://stackoverflow.com/help/minimal-reproducible-example) as this often reveals the answer yourself
- Include version, environment, and what you have already tried
- Screenshots help, but provide any code or error messages as text

## Reporting a Bug

Suspected defects are reported via the [issue templates](https://github.com/ByteCorum/pyguard/issues/new/choose).

Use **Bug Report** and fill in every section. Search [existing issues](https://github.com/ByteCorum/pyguard/issues) first, including closed ones.

## Requesting a Feature

Use the **Feature Request** template at [issues](https://github.com/ByteCorum/pyguard/issues/new/choose).
Describe the problem you are trying to solve, not only the solution.

## Documentation Issues

Errors and gaps in the documentation are reported with the **Documentation Issue** template.

## Security Vulnerabilities

Do not open a public issue. Report via Security and quality [tab](https://github.com/ByteCorum/pyguard/security/advisories/new). Reports are handled privately and responsibly.

## Contact author

Current contact options are listed in the [owner profile](https://github.com/ByteCorum)

## What Not to Do

- Do not open issues for usage questions as they will be redirected to Discussions
- Do not email maintainers directly about support matters, because public questions get public answers, which benefits everyone
- Do not open duplicate issues or add "+1" comments to existing ones
- Do not report security or conduct matters in the issue tracker
